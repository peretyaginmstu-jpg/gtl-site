# Сайт ООО «ГТЛ Система»

Одностраничный сайт: поставка промышленных станков, монтаж, сервис, инжиниринг и программное обеспечение.
Статика без сборки — `index.html`, стили и скрипты внутри него, иллюстрации в `assets/`.

## Посмотреть локально

```bash
python3 -m http.server 4173
```

После этого сайт открыт на http://localhost:4173/. Можно и просто открыть `index.html` в браузере.

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | Вся страница: разметка, стили, скрипты |
| `assets/art.js` | Живые иллюстрации: движок изометрической графики и семь сцен |
| `assets/*.svg` | Статичные кадры тех же сцен — для браузеров без JavaScript |
| `tools/snapshot.mjs` | Пересобирает статичные кадры из `assets/art.js` |
| `tools/check.mjs` | Проверяет сцены без браузера; запускается перед выкладкой |
| `.github/workflows/release.yml` | Выкладка сайта при публикации релиза |

## Контакты

Телефон и e-mail вписываются в одном месте — в объекте `CONFIG` в конце `index.html`:

```js
const CONFIG = {
  phone: '',   // например '+7 (495) 000-00-00'
  email: ''    // на этот адрес будет уходить заявка
};
```

Пока поля пустые, контакты на странице не показываются, а заявка открывается письмом без адресата.

## Иллюстрации

Каждый рисунок — небольшая модель: в покое это чертёж, под курсором он оживает и показывает расчёт.
На станке первого экрана есть две кнопки: бронзовая «Пуск» запускает очередную программу обработки, тёмная «Стоп» прерывает её.

На сенсорном экране рисунком управляет палец: ведёшь вбок или после короткой паузы — сцена идёт за пальцем,
быстрый вертикальный жест прокручивает страницу. Короткое касание работает как щелчок, долгое — как зажатая кнопка.

Сцены описаны в `assets/art.js`. После правок:

```bash
node tools/snapshot.mjs
```

```bash
node tools/check.mjs
```

Первая команда обновляет статичные кадры, вторая проверяет, что сцены работают без ошибок.

## Выкладка

Сайт выкладывается на GitHub Pages экшном «Релиз сайта» — он запускается, когда на GitHub публикуется релиз:

```bash
gh release create v1.1.0 --generate-notes
```

Экшн проверяет иллюстрации, собирает сайт, прикладывает к релизу архив `gtl-site-<версия>.zip` и обновляет страницу.
Запустить выкладку без нового релиза можно вручную со вкладки Actions.
